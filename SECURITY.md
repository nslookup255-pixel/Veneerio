# Security Policy

## Supported Versions

Veneerio is under active development and has not yet reached "1.0.0".

Security fixes are provided on a best-effort basis for the latest version on the default branch. Older versions and commits are not guaranteed to receive security updates.

Version| Supported
| --- | -- |
Latest development version| :white_check_mark:
Older versions and commits| :x:

## Reporting a Vulnerability

If you discover a potential security vulnerability in Veneerio, please report it responsibly.

Please do not report security vulnerabilities through public GitHub issues or pull requests.

Use "GitHub's private vulnerability reporting" (https://github.com/nslookup255-pixel/Veneerio/security/advisories/new) to submit a report privately.

When reporting a vulnerability, please include:

- A description of the vulnerability and its potential impact.
- The affected version, commit, or component.
- Steps to reproduce the issue, including a proof of concept if available.
- Any suggested mitigations or fixes, if known.

## What to Expect

- Acknowledgment: We aim to acknowledge reports within 7 days.
- Updates: We aim to provide updates at least every 14 days while investigating a report.
- Accepted reports: We will assess the impact, work on an appropriate fix, and coordinate disclosure with the reporter.
- Declined reports: If a report is determined not to be a security vulnerability, we will explain the reasoning where possible.

These timelines are goals rather than guarantees, as Veneerio is an actively developed project maintained on a best-effort basis.

Please allow the maintainer reasonable time to investigate and address a vulnerability before publicly disclosing it. Thank you for helping keep Veneerio and its users safe.
